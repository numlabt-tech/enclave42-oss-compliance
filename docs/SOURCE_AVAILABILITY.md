# Corresponding source for the LGPL libraries in Enclave42 SDK 0.1.2

**Status: provisional. This is not a final written offer.** The formal terms (period of availability, final wording) have not been defined in the legal advice communicated to Enclave42, so none are promised here.

What is provided today, without charge:
- `enclave42-0.1.2-lgpl-corresponding-sources.tar` in the release `oss-g2-0.1.2-v1` of this repository: the upstream source tarballs, Ubuntu `.dsc` and Debian patch tarballs (including security patches) of the nine source packages behind the ten LGPL libraries (libgmp, libnettle, libhogweed, libgnutls, libidn2, libunistring, libtasn1, libkeyutils, librtmp, libssh). Each file's SHA-256 is listed in `SHA256SUMS` (archive) and verified against the `.dsc` (see `sources/` in the compliance archive).
- The same files are published by Ubuntu at archive.ubuntu.com (exact URLs in `LGPL-LIBRARIES.json`).
- Licence texts, upstream licence files and `debian/copyright` in `enclave42-0.1.2-oss-compliance-g2-0.1.2-v1.tar.gz`.

Requests and questions: **support@enclave42.com**.
Replacement of a bundled library: see `LGPL_REPLACEMENT_PROCEDURE.md`.
