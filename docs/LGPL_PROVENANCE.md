# Provenance of the ten LGPL libraries in Enclave42 SDK 0.1.2

Technical provenance record. Not legal advice. Contact: support@enclave42.com. Wheel: `enclave42-0.1.2-py3-none-manylinux_2_39_x86_64.whl`, sha256 `d7fb0e7cb7aa607f7a634d6c0824616f1953447161a49bad158c474153833555`.

## What was verified (2026-10-13)
- Each library in the wheel has code sections (`.text`, `.rodata`, `.data`, `.eh_frame`, …) identical to the exact Ubuntu 24.04 `.deb`, and is reproduced **byte for byte** from that `.deb` by one `patchelf` 0.19.1 invocation ([inventory/relink-recipe-lgpl-libs.json](../inventory/relink-recipe-lgpl-libs.json)). Only the SONAME, NEEDED and RPATH strings differ from the Ubuntu binary.
- 9 source packages: every file's SHA-256 matches the Ubuntu `.dsc`; 43 of 43 source/`.dsc`/`.deb` URLs answered HTTP 200, first on 2026-10-13 (`source-urls-http-check-2026-10-13.json`) and again for v2 (`source-urls-http-recheck-for-v2.json`) ([inventory/verification/](../inventory/verification/)). The versions are the ones currently Published for Noble at that date.
- Upstream GPG signatures: 6 of 9 verify with the keys shipped in the Debian packaging (key trust not independently established); gmp, keyutils and rtmpdump have none.
- Licences were determined from the per-file headers of the exact sources (counts in `LGPL-LIBRARIES.json`, `per_file_header_scan`).

## Integrity control and limits

The SDK refuses to use a bundled library whose SHA-256 differs from the table `VENDORED_SHA256` in `confidential/providers/backend_01/packaged_nvattest.py`, and refuses an inventory of `enclave42.libs/` that differs from that table (fail-closed: the GPU attestation dimension is then reported as not verified, never as verified). This control was **not** disabled or modified. Consequences, measured on a scratch copy of the wheel: replacing a library without updating the table is refused; replacing it **and** updating the table is accepted; adding or renaming files is refused. See [LGPL_REPLACEMENT_PROCEDURE.md](LGPL_REPLACEMENT_PROCEDURE.md).

Not claimed: legal sufficiency of this mechanism; no availability period for the sources is stated ([SOURCE_AVAILABILITY.md](SOURCE_AVAILABILITY.md)).
